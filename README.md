## 🆕 V1.1 更新内容

### 库存管理
- **进价列**：库存列表新增当前进价显示，一目了然
- **价格波动入库**：入库时可输入新进价，系统自动计算加权平均进价并写入日志
- **撤销回退进价**：撤销价格波动入库时，进价同步回退到波动前的值

### 财报分析
- **畅销排行 ×2**：新增**销量 TOP10** 和**销售额 TOP10** 排行榜，基于全历史销售数据
- **入库建议升级**：支持自定义 7/14/30/60/90 天销量范围，按所选天数计算日均销量和建议入库量

### 销售记录
- **商品历史销量**：左侧显示全部商品列表（库存/销量/销售额），选中商品后下方展示该商品每次销售的日期/单号/数量/小计
- **独立搜索栏**：左右各自搜索，互不影响
- **可拖拽分割面板**：PanedWindow 布局，拖动中间竖线自由调整左右比例

### 数据导出
- **库存日志导出**：CSV/Excel 新增库存日志导出
- **一键全部 Excel**：新增加"库存日志"Sheet
- **库存 CSV**：补上进价列
- **备份 ZIP**：每日自动备份包含库存日志.xlsx

### Bug 修复
- 撤销价格波动入库时进价不回退（已根治：日志内嵌旧进价，撤销时精确解析）
- `sqlite3.Row` 没有 `.get()` 方法导致导出崩溃（统一改用 `[]` 索引）
- 导出备注中隐藏内部标记前缀，用户只看到自己输入的备注
- 同条码多商品扫码时弹窗选择，避免歧义
- 源头去掉 barcode UNIQUE 约束，自动迁移旧库

## 📸 功能一览

| 模块 | 功能 |
|------|------|
| 🧾 **收银台** | 商品浏览、条码扫码枪、购物车 ±/删除/改数量、**会员选择弹窗**（模糊搜索）、**会员价自动切换**、**积分兑换**、现金找零 |

## 🚀 快速开始

### 1. 安装 Python 3.8+

```bash
# 检查版本
python --version   # >= 3.8
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动

```bash
python main.py
```

> 💡 首次启动会自动创建 `data/cashier.db` 空数据库。

---

## 📦 打包为 exe

```bash
pip install pyinstaller==5.13.2
pyinstaller SYTCashier.spec
```
打包完成后 `dist/SYTCashier.exe` 即为独立可执行文件，拷贝到任意电脑直接双击运行。

> ⚡ 或者直接安装 Python 3.8，双击 `SYTCashier.exe` 即可使用。

## ⌨️ 扫码枪使用

软件内置扫码枪监听，即插即用：

- 扫码枪自动识别为键盘输入
- 扫描商品条码 → 自动加入购物车
- 同条码多商品时弹出选择窗口
- 无需额外驱动或配置
